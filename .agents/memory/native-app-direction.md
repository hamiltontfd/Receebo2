---
name: Direção das versões nativas
description: O Web/PWA é a referência do produto; futuras versões para lojas serão apenas uma casca do mesmo PWA.
---

O Receebo Mobile atual não corresponde mais à realidade do produto. Quando forem lançadas versões nativas iOS ou Android, serão apenas uma casca para as lojas que replique o mesmo PWA do Receebo Web, não uma experiência mobile independente.

**Why:** O usuário definiu essa direção para o produto.

**How to apply:** Usar o Receebo Web/PWA como referência ao avaliar o estado do produto e planejar versões para as lojas. Não tratar o projeto mobile atual como a experiência pretendida para o lançamento nativo.
