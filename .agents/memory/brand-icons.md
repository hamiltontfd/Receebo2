---
name: Brand icons
description: User requirements for Receebo browser and installed-app icons.
---
Use the symbol from the original Receebo SVG, without the wordmark, for both the website favicon and installed-app icons. The background must be white.

**Why:** The user explicitly requested consistent original-symbol icons on a white background after seeing a differently drawn installation icon.

**How to apply:** Preserve the original vector geometry when regenerating icons and retain sufficient padding for platform icon masks.
